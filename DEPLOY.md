## 1. Коммит и пуш на GitHub

### Проверить, что изменилось:
```bash
git status
git diff --stat
```

### Добавить изменённые файлы:
```bash
# Добавить конкретные файлы
git add main.py database.py routers/waifu_cat.py

# Или добавить все изменения
git add .
```

### Создать коммит:
```bash
git commit -m "Описание изменений"
```

### Отправить на GitHub:
```bash
git push
```

> ⚠️ **Важно:** Не добавляй файл `.env` в коммит — в нём хранятся секреты!

## 3. Обновление на сервере

### Перейди в директорию бота:
```bash
cd /home/kiberrelk/bots/MellisaChatBot
```

### Загрузи обновления с GitHub:
```bash
git pull origin master
```

### Проверь, что обновления применились:
```bash
git log --oneline -3
```

---

## 4. Перезапуск бота

```bash
pm2 restart Melissa
```

### Проверь статус:
```bash
pm2 list
```

Должен отображаться статус **online** ✅

---

## 5. Проверка логов

```bash
pm2 logs Melissa --lines 50
```

### Что должно быть в логах при успешном старте:
```
✅ Глобальное соединение с БД users.db установлено
✅ База данных готова
✅ Запуск бота MellisaChatBot...
✅ Start polling
✅ Run polling for bot @TeaDyNastybot
```

### Если видишь ERROR — скопируй строку и разберись с ошибкой перед продолжением.

## 6. Редактирование .env

Если нужно добавить или изменить переменные окружения:

```bash
cd /home/kiberrelk/bots/MellisaChatBot
nano .env
```

**Управление в nano:**
| Действие | Команда |
|----------|---------|
| Сохранить | `Ctrl + O` → `Enter` |
| Выйти | `Ctrl + X` |

### После изменения .env — перезапусти бота с обновлением переменных:
```bash
pm2 restart Melissa --update-env
```

## 7. Полезные команды PM2

| Команда | Описание |
|---------|----------|
| `pm2 list` | Список всех процессов |
| `pm2 restart Melissa` | Перезапустить бота |
| `pm2 restart Melissa --update-env` | Перезапустить с обновлением .env |
| `pm2 stop Melissa` | Остановить бота |
| `pm2 start Melissa` | Запустить бота |
| `pm2 logs Melissa` | Логи в реальном времени |
| `pm2 logs Melissa --lines 50` | Последние 50 строк логов |
| `pm2 save` | Сохранить конфигурацию |
| `pm2 monit` | Мониторинг CPU/RAM в реальном времени |

## ✅ Полный цикл обновления (шпаргалка)

```bash
# 1. Локально — коммит и пуш
git add .

git push

# 2. На сервере — загрузить и перезапустить
cd /home/kiberrelk/bots/MellisaChatBot
git pull origin master
pm2 restart Melissa

# 3. Проверить логи
pm2 logs Melissa --lines 30
```
