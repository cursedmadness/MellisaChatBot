# 🤖 MellisaChatBot - Технический обзор

[![Python](https://img.shields.io/badge/Python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![Framework](https://img.shields.io/badge/Framework-Aiogram_3.x-red.svg)](https://docs.aiogram.dev/)
[![Database](https://img.shields.io/badge/Database-AioSQLite-lightgray.svg)](https://github.com/omnilib/aiosqlite)

**MellisaChatBot** — это высокопроизводительный, полностью асинхронный Telegram-бот, разработанный для управления сообществами, геймификации (система Waifu Cat) и отслеживания активности. Создан с упором на масштабируемость и современные асинхронные паттерны.

---

## 🏗️ Архитектура и Технологический стек

Проект прошел через масштабный рефакторинг архитектуры, перейдя от гибридной системы к **единой асинхронной экосистеме**.

*   **Основной фреймворк:** [Aiogram 3.x](https://docs.aiogram.dev/) — использование высокоуровневых систем Dispatcher, Routers и Filter.
*   **Асинхронный I/O:** Полная совместимость с `asyncio`, обеспечивающая неблокирующее выполнение событийного цикла.
*   **Хранение данных:** [AioSQLite](https://github.com/omnilib/aiosqlite) — предоставляет асинхронный интерфейс для SQLite, предотвращая блокировки I/O при высокой нагрузке.
*   **Модульная маршрутизация:** Разделенная архитектура, где функционал распределен по специализированным роутерам (Admin, Moderation, Hebao, Waifu и т.д.).
*   **Динамические фоновые задачи:** Встроенный планировщик для ежедневных наград, отчетов и очистки наказаний, работающий внутри цикла `asyncio`.

## 🛠️ Основные возможности (Технические и Функциональные)

### 👮 Унифицированная система модерации
*   **Отсутствие конфликтов:** Полный переход с Pyrogram на нативные методы Aiogram для операций бан/мут/варн.
*   **Автоматическая очистка:** Фоновые задачи периодически проверяют и снимают истекшие наказания как в БД, так и в ограничениях Telegram.
*   **Логирование аудита:** Подробное ведение логов в базе данных для всех административных действий.

### 🍱 Геймификация: Waifu и Hebao
*   **Продвинутый инвентарь (Hebao):** Масштабируемая система предметов с гибкостью JSON-структур внутри SQLite.
*   **Управление Waifu Cat:** Сложное управление состоянием питомцев, включая сытость, настроение и интерактивную логику кормления.
*   **Интерактивный UI:** Автоматическая генерация кликабельных ссылок на пользователей (HTML-форматирование) вместо сырых ID для улучшения UX.

### 📊 Отслеживание активности и Аналитика
*   **Гранулярные метрики:** Отслеживание частоты сообщений каждого пользователя и вовлеченности по дням/месяцам.
*   **Автоматическая отчетность:** Генерация статистических отчетов через заданные интервалы (на базе UTC).
*   **Лидерборды:** Оптимизированные запросы для генерации топов пользователей в реальном времени.

## 🚀 Развертывание и Конфигурация

### Переменные окружения
Создайте файл `.env` в корневой директории:
```env
BOT_TOKEN=7573521471:AA...  # Токен вашего бота
ADMIN_IDS=123,456           # ID глобальных администраторов через запятую
```

### Установка
```bash
# Клонируйте репозиторий
git clone https://github.com/your-repo/MellisaChatBot.git

# Установите зависимости
pip install -r requirements.txt

# Запустите техническую диагностику
python check_bot.py

# Запустите бота
python main.py
```

## 🔐 Безопасность и Best Practices

*   **Маскирование учетных данных:** Переменные окружения используются для всей чувствительной конфигурации.
*   **Строгий GitIgnore:** Файлы `.session`, `.env` и `.db` явно исключены из системы контроля версий.
*   **Санитайзинг ввода:** Глубокая логика резолва пользователей в `utils.py` безопасно обрабатывает упоминания, ID и ссылки.
