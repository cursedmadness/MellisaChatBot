# MellisaChatBot

Telegram бот с системой кошек-жен, инвентарем риса и статистикой активности.

## 🚀 Быстрый старт

### 1. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
TOKEN=ваш_токен_бота
API_ID=ваш_api_id
API_HASH=ваш_api_hash
```

**Получение API_ID и API_HASH:**
1. Перейдите на https://my.telegram.org/
2. Авторизуйтесь с номером телефона
3. Создайте новое приложение
4. Скопируйте `api_id` и `api_hash`

Пример содержимого файла `.env` можно посмотреть в `env_example.txt`.

### 1.1 Проверка конфигурации

Перед запуском проверьте настройки:

```bash
python check_bot.py
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск бота

```bash
python main.py
```

## 🔧 Диагностика и troubleshooting

### Проверка конфигурации
```bash
python check_bot.py
```

### Возможные проблемы

**Бот не отвечает на команды модерации (/бан, /мут, /варн):**
- Проверьте, настроены ли `API_ID` и `API_HASH` в `.env`
- Запустите `python check_bot.py` для диагностики
- Получите API ключи на https://my.telegram.org/

**Бот не запускается:**
- Проверьте токен бота в `.env`
- Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`
- Запустите диагностику: `python check_bot.py`

**Команды не работают:**
- Используйте команду `статус модерации` для проверки
- Проверьте логи в консоли при запуске

## 📋 Основные возможности

### Кошки-жены
- `поймать котенка` - создать кошку-жену
- `моя кошка` - посмотреть свою кошку
- `кошка @username` - посмотреть чужую кошку
- `покормить` - накормить кошку рисом

### Инвентарь (Хэбао)
- `хэбао` - посмотреть свой инвентарь
- `хэбао @username` - посмотреть чужой инвентарь

### Статистика активности
- `статистика` - посмотреть текущую статистику
- Автоматические ежедневные и ежемесячные отчеты

### Правила чата
- `создать правила [текст]` - создать правила (только админы)
- `правила` - посмотреть правила

### Модерация (требует API_ID и API_HASH)
- `/бан @username [причина]` - забанить пользователя
- `/разбан @username` - разбанить пользователя
- `/мут @username [минуты]` - замутить пользователя
- `/размут @username` - размутить пользователя
- `/варн @username [причина]` - выдать предупреждение
- `/снять_варн @username` - снять предупреждение
- `/наказания @username` - просмотреть наказания

### Админ-команды
- `обнулить @username` - удалить пользователя
- `статус модерации` - проверить работу системы модерации
- `сбросить рис` - сбросить рис всем до 1 миски

## ⚙️ Конфигурация

Все настройки находятся в `config.py`. Основные параметры:
- `DAILY_RICE_TIME_HOUR` - час ежедневной выдачи риса (UTC)
- `MAX_RICE_PER_USER` - максимум риса у пользователя
- `ADMIN_IDS` - ID администраторов

## 📊 Система риса

- Ежедневная автоматическая выдача в 9:00 UTC
- Максимум 6 мисок на пользователя
- Используется для кормления кошек
- Новые пользователи получают 1 миску при регистрации

## 📈 Статистика активности

- Сбор статистики в указанных чатах
- Ежедневные отчеты в 00:00 UTC
- Ежемесячные отчеты в последний день месяца в 23:59 UTC
- Топ-5 ежедневно, топ-30 ежемесячно


### Добавление новых команд

1. Создайте новый роутер в папке `routers/`
2. Добавьте импорт в `routers/__init__.py`
3. Зарегистрируйте роутер в `main.py`
